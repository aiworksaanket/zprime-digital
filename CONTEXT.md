# Domain

- **Studio site** — the single-page marketing surface for Zprime Digital.
- **Service** — one of five disciplines in the growth engine (SEO, paid, lead gen, social, content).
- **Process loop** — the five-step monthly cycle (audit → strategy → execute → optimise → report), not a one-off project.
- **Inquiry** — a request for a free audit. Validated in the Inquiry module, then composed through the mailto adapter.
